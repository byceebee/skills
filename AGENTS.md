# CeeBee Skills

Keep each installable skill under `skills/<skill-name>/`. Its `SKILL.md` must match the directory name. Bundle scripts and examples that the skill needs at runtime inside that directory.

Use fictional fixtures and portable paths. Keep credentials, internal repository names and paths, and browser captures out of commits. Document and test each skill from an isolated install that contains only the files its users receive.
